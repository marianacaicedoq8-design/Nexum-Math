# NEXUM MATH — Plataforma Educativa Gamificada de Matemáticas

NEXUM MATH es una aplicación web interactiva diseñada para estudiantes de noveno, décimo y once grado. Combina la gamificación estilo videojuego cyberpunk/dark gamer con un tutor pedagógico en inteligencia artificial (Nex) para garantizar el aprendizaje activo de matemáticas.

## 🚀 Características Principales

1. **Selección e Independencia de Grados:**
   - 9.º Grade: Álgebra, Ecuaciones, Productos Notables, Factorización, Estadística.
   - 10.º Grade: Funciones Lineales/Cuadráticas, Trigonometría, Logaritmos, Geometría Analítica.
   - 11.º Grade: Límites, Derivadas, Cálculo, Vectores, Preparación ICFES Saber 11.

2. **Generador Procedural de Ejercicios:**
   - Motor dinámico parametrizado capaz de generar miles de variaciones numéricas y algebraicas sin repeticiones duplicadas.

3. **Tutor Inteligente IA 'Nex':**
   - Acompañante inteligente con sistema de pistas progresivas de 3 niveles y explicaciones paso a paso sin dar la respuesta directamente.

4. **Evaluaciones Automáticas cada 10 Ejercicios:**
   - Sistema de checkpoints con desglose de precisión, tiempo, recomendaciones personalizadas y calificación de 1 a 5 ⭐ Estrellas.

5. **Gamificación Completa:**
   - Puntos (PTS), Experiencia (XP), Rachas Diarias, Insignias, Modos de Juego (Historia, Duelo Mental, Jefe Final, Supervivencia).

6. **Laboratorio Matemático:**
   - Espacio interactivo de exploración de funciones gráficos e hiperparámetros.


## 💻 Instrucciones de Uso / Ejecución

1. Descarga y extrae el archivo ejecutable comprimido `nexum-math-app.zip`.
2. Haz doble clic en `index.html` para abrirlo directamente en cualquier navegador moderno (Chrome, Edge, Firefox, Safari).
3. ¡No requiere instaladores ni servidores Node.js adicionales! Todos los módulos (React, Tailwind, Lucide Icons) están optimizados mediante CDN.
